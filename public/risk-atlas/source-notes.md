# 五类风险绘图数据

坐标系：WGS 84 / UTM zone 51N（EPSG:32651），坐标单位米。

## 文件

- 建筑风险_四类共享几何.parquet：上海市域内建筑多边形，四类原始risk、活动对数值，以及开发建设IDW结果与平滑场取样。采用GeoParquet + ZSTD压缩，共用几何以减少体积。
- 文物点风险_含舆论反向值.parquet：全部767条文物点，含四类原始risk及舆论反向值。情感表708个名称对应745条点记录，22条无评分记录保留NaN，不能按零风险处理。
- 绘图栅格/：当前四类建筑风险图实际使用的全域与中心城区GeoTIFF，保留未按色阶上下限截断的数值。开发建设为最新IDW＋300m高斯平滑展示场，其他三类为原始risk栅格；舆论为点位表达，见文物点文件。
- 上海市域边界.gpkg：绘图裁切边界。

## 关键字段

| 字段 | 含义 |
|---|---|
| bd_id | 源建筑/点位记录ID，可与四个原始风险图层按此字段连接 |
| risk_bendi_raw | 本底塑造原始risk |
| risk_kaifa_raw | 开发建设原始risk，0为源值，不自动当作缺失 |
| risk_huodong_raw | 活动利用原始risk |
| risk_huodong_log1p | ln(1+原始活动risk)，当前活动图的显示变换 |
| risk_weihuapin_raw | 危化品原始risk |
| risk_kaifa_idw | 零值建筑局部IDW估计后数值；非估计记录保留原值 |
| kaifa_idw_flag | 0=未作IDW；1=零值建筑有支持的IDW估计；2=零值建筑邻点不足、保留0 |
| kaifa_nearest_donor_m | IDW获支持建筑到最近正风险建筑质心的距离；未估计为NaN |
| risk_kaifa_smooth_sample | 对当前40m插值平滑展示栅格在建筑内部代表点取样，并非原始建筑risk；以GeoTIFF为完整展示依据 |
| sentiment_score_0_100 | 原始全量NLP情感得分；高值更偏正面 |
| risk_yulun_0_100 | 舆论负向风险指标=100-情感得分；高值负向程度更高 |
| risk_yulun_0_1 | 上述指标除以100；仅统一取值范围，不代表发生概率 |
| has_yulun_score | 是否存在匹配评分 |

## 计算与显示

开发建设IDW：在5km内选最近8栋原始risk>0的建筑质心，至少3个邻点；权重=1/max(距离,1m)^2。仅给原始零值建筑生成空间估计，随后在统一40m建筑覆盖网格做标准差300m的高斯平滑。未考虑河流等阻隔；原始risk未修改。

色阶：本底0–1；开发建设展示场0–1.2；活动采用ln(1+x)色阶、原值刻度0–80000；危化品0.25–20；舆论负向风险显示0–40。超显示上限同色显示，导出数据完整保留原值。

原始四类风险按bd_id连接；共享建筑几何取自本底原始图层，并在市域边缘裁切。其他源图层坐标精度可能略有差别，若需要各自原始几何，请按bd_id回连源GPKG。数据记录未抽样。

40m与8m为近似显示分辨率，精确仿射变换见GeoTIFF。原图采用all_touched栅格化，小建筑显示面积可能放大。GeoTIFF行政区边缘按像元掩膜，精确边界见附带GPKG。

情感模型为未筛选相关性及评价主体的全量预测均值；反向指标是展示性风险代理，不等同于真实负面舆情发生概率或公众满意度。

导出后校验：全部原始risk及变换字段通过复核。73栋建筑的内部代表点未落入有效的40m平滑显示像元，risk_kaifa_smooth_sample保留NaN，不补造；需要完整平滑展示场时以所附GeoTIFF为准。
